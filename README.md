# Portfolio Express - Patri Escudero 💄✨

Web personal y portafolio interactivo para **Patri Escudero**, Maquilladora Profesional especializada en Beauty, Caracterización escénica y Efectos Especiales (FX).

---

## 📋 Resumen del Proyecto

"Portfolio Express" es una aplicación web moderna, limpia y responsive desarrollada con **HTML5, CSS3 y JavaScript puro (Vanilla JS)**. El diseño está inspirado en editoriales de moda y belleza de alta gama, con una paleta cromática clara en tonos marfil, nude cálido y terracota, tipografía sofisticada y microinteracciones fluidas.

---

## 🚀 Secciones y Características

### 1. Hero Principal
- **Identidad:** Título con el nombre *"Patri Escudero"* y subtítulo *"Maquilladora Profesional"*.
- **Llamada a la acción (CTA):** Botón principal *"Ver proyectos"* con desplazamiento suave (*smooth scroll*) hacia el portafolio, y botón secundario *"Contactar"*.
- **Elemento visual:** Tarjeta con estética de pasarela y badges flotantes (*Editorial, Cine & TV, FX*).

### 2. Sobre Mí
- Resumen profesional con enfoque en técnica estética, iluminación de estudio y adaptabilidad audiovisual (HD/4K).
- Métricas destacadas: Compromiso, volumen de producciones y estándar fotográfico.
- Puntos de valor sobre productos de alta gama y asesoramiento de visagismo.

### 3. Habilidades (Especialidades)
Tarjetas con bordes redondeados y diseño limpio para cada categoría técnica:
- **Beauty:** Maquillaje social, novias, editoriales de moda, técnicas glow y piel efecto porcelana.
- **Caracterización:** Transformación para cine y teatro, envejecimiento pictórico, posticería y personajes de época.
- **Fx:** Efectos especiales hiperrealistas, colocación y pintado de prótesis de silicona y látex, heridas y sangre escénica.
- **Otros:** Aerografía cosmética, diseño de Face Charts, docencia/automaquillaje y dirección de maquillaje en set.

### 4. Proyectos
Tres tarjetas de muestra con etiquetas de estilo, metadatos y descripciones:
1. **Editorial "Luz & Sombras":** Campaña fotográfica de alta costura centrada en texturas húmedas y pigmentos metálicos.
2. **Caracterización "El Olvido":** Cortometraje dramático con diseño de personaje y desgaste físico adaptado a cámara.
3. **Criaturas del Abismo (FX):** Modelado y aplicación de prótesis de silicona encapsulada con texturas hiperrealistas.

### 5. Contacto Interactivo
- **Redes y ubicación:** Tarjeta directa de Instagram enlazada a **`@patrimakeupartist`** y disponibilidad para desplazamientos (correo privado oculto según preferencias).
- **Botón "Contactar":** Despliega un modal interactivo con formulario de propuesta (nombre, correo, servicio requerido y mensaje).
- **Notificación Toast:** Al enviar el formulario, se muestra un mensaje emergente de confirmación interactivo.

### 6. Navegación y Footer
- Barra de navegación fija (*sticky*) con efecto de desenfoque (*glassmorphism*) y detección de sección activa.
- Menú móvil desplegable con botón hamburguesa accesible.
- Pie de página con enlaces a redes sociales y créditos de autoría.

---

## 🛠️ Tecnologías Empleadas

- **HTML5:** Estructura semántica, accesible y preparada para SEO.
- **CSS3:** Variables CSS para sistema de diseño, Flexbox, CSS Grid, animaciones de hover y diseño completamente adaptativo (*Mobile-First / Responsive*).
  - **Tipografías:** *Cormorant Garamond* (títulos editoriales) y *Plus Jakarta Sans* (texto limpio y legible).
  - **Iconografía:** Font Awesome 6.
- **JavaScript (ES6+):** Lógica sin dependencias externas para apertura y cierre de modal, menú móvil, scroll dinámico y notificaciones toast.

## 💻 Visualización Local

Para abrir el proyecto en local:

1. Clona el repositorio o accede a la carpeta:
   ```bash
   git clone https://github.com/patriciaescudero31/paginadepresentaci-n.git
   cd paginadepresentaci-n
   ```
2. Abre `index.html` en tu navegador preferido:
   ```bash
   open -a "Google Chrome" index.html
   ```
